
# Pragma Design System Showcase

Este proyecto es la app de ejemplo y documentación visual del Pragma Design System. Permite explorar, probar y visualizar todos los componentes, templates y páginas disponibles en la librería.

## ¿Para qué sirve?

- Ver en tiempo real el aspecto y comportamiento de cada componente.
- Consultar ejemplos de uso y configuración.
- Probar la integración de los componentes en diferentes escenarios.
- Servir como referencia para desarrolladores y diseñadores.

## ¿Cómo lo ejecuto?

1. Asegúrate de tener las dependencias instaladas:
	```sh
	flutter pub get
	```
2. Ejecuta la app showcase:
	```sh
	flutter run
	```

Esto abrirá la app en un emulador o dispositivo físico, donde podrás navegar por todas las vistas de componentes.

## Estructura principal

- `lib/views/`: Vistas de ejemplo para cada capa (tokens, foundations, atoms, molecules, organisms, templates, pages).
- `lib/main.dart`: Punto de entrada de la app showcase.
- `assets/`: Recursos gráficos usados en los ejemplos.

## ¿Cómo uso los ejemplos?

Cada vista muestra ejemplos de implementación real de los componentes. Puedes copiar y adaptar estos fragmentos en tu propio proyecto.

## Personalización

Puedes modificar los archivos de la carpeta `views/` para crear nuevos ejemplos, probar variantes o documentar nuevos componentes.
